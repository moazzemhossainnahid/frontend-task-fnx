# FinixCode Frontend Assignment

This project is an Assignment of the FinixCode using Next.js 15, TypeScript, and Tailwind CSS.

![Project Screenshot](https://imagedelivery.net/upczkOXHorYX26Lz6iRC9A/241a106c-e7c1-4530-8a72-35e75917ff00/public)

## 📌 Features

- Pixel-perfect implementation matching the provided Figma design
- Custom font implementation using Satoshi font family
- Interactive components with proper state management
- Clean, maintainable code structure following best practices
- Type-safe development with TypeScript
- Performance optimized with Next.js best practices

## 🚀 Live Demo

Check out the live demo: [Assignment Demo](https://frontend-task-fnx.vercel.app)

## 🛠️ Technologies Used

- [Next.js 15](https://nextjs.org/) - React framework with App Router
- [TypeScript](https://www.typescriptlang.org/) - For type safety
- [Tailwind CSS](https://tailwindcss.com/) - For styling
- [React](https://reactjs.org/) - UI library
- Custom Satoshi font family

## 🧰 Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.17.0 or higher)
- [npm](https://www.npmjs.com/), [yarn](https://yarnpkg.com/), [pnpm](https://pnpm.io/), or [bun](https://bun.sh/)

## ⚙️ Installation & Setup

1. Clone the repository
   ```bash
   git clone https://github.com/moazzemhossainnahid/frontend-task-fnx.git
   cd frontend-task-fnx
   ```

2. Install dependencies
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. Run the development server
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
